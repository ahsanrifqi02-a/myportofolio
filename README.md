### Tugas 3

1. Saya menggunakan ModelForm alih-alih membuat form HTML manual karena ModelForm secara otomatis menghubungkan model yang sudah kita buat ke form input. Hal ini memudahkan saya karena tidak perlu menulis tag satu per satu secara manual di template, dan validasi tipe datanya sudah otomatis di-handle oleh Django saat kita memanggil form.is_valid(). Selain itu, ModelForm menyediakan fungsi .save() bawaan yang langsung menyimpan data ke database tanpa perlu repot menulis query create manual. Sedangkan tag {% csrf_token %} wajib ditambahkan untuk keamanan, yaitu mencegah serangan CSRF (Cross-Site Request Forgery) di mana web luar yang berbahaya mencoba mengirimkan request POST atas nama sesi kita tanpa izin. Dengan token ini, Django akan memverifikasi bahwa request form tersebut memang sah dan berasal dari website kita sendiri.
2. JSON lebih disukai dibanding XML dalam web modern karena formatnya jauh lebih simpel dan ringan (lightweight). JSON menggunakan format key-value yang ringkas sehingga ukuran file yang dikirim lewat jaringan jauh lebih kecil dan hemat bandwidth, tidak seperti XML yang harus menggunakan tag pembuka dan penutup berulang-ulang yang membuat datanya panjang dan berat. Selain itu, JSON didukung secara native oleh JavaScript di browser sehingga bisa langsung di-parse dengan cepat menggunakan fungsi bawaan JSON.parse() tanpa perlu parser XML DOM yang rumit, serta strukturnya jauh lebih mudah dibaca dan di-handle oleh developer maupun framework frontend modern.
3. Alurnya dimulai ketika ada request yang masuk ke URL endpoint (misalnya /api/education/), lalu URL routing akan mengarahkan request tersebut ke fungsi view terkait (seperti get_education_json). Di dalam view, Django akan mengambil data dari database menggunakan ORM (seperti Education.objects.all()), kemudian data objek tersebut di-serialize menggunakan serializers.serialize('json', queryset) menjadi format teks JSON, lalu dikembalikan ke browser sebagai HttpResponse dengan tipe application/json. Kita wajib melakukan proses serialization terlebih dahulu karena data yang diambil dari model Django masih berbentuk objek Python kompleks di memori server yang memiliki tipe data khusus (seperti UUID dan DateTime) yang tidak bisa dikirim langsung lewat HTTP. Proses serialization ini bertindak sebagai penerjemah yang mengubah objek Python tersebut menjadi format teks standar universal (JSON) agar bisa dibaca dan dipahami oleh browser atau aplikasi lain.
